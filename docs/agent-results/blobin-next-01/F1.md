## Produit réalisé — portée exacte

Nouvelle implémentation Rust/WGSL **clean-room**, sous `experiments/blobin-next-01/F1/` :

- `FrameIr` canonique : largeur/hauteur logique, DPR, phase, focus, `entity_id`, `topology_epoch`, digest sémantique déterministe indépendant du fournisseur et du DPR.
- `cpu_render` : rendu logiciel sans accès GPU, RGBA opaque, champ organique radial, un trou véritable, contour et éclairage de biseau de focus.
- `gpu::render` : shader compute WGSL original, `wgpu 30.0.1` Vulkan, buffer GPU RGBA hors écran et readback vérifiable. **Pas de dessin via Qt ni GPUI**.
- `diff_images` : différence absolue par canal et comparaison d'images; oracle volontairement falsifiable.
- CLI `cpu|gpu|auto|compare`; `auto` bascule CPU en cas d'erreur GPU ou de panne injectée avant dispatch.
- `Cargo.lock` figé à partir du cache local (`--offline`), `publish=false`; PNG de preuve synthétiques privés dans `fixtures/qualification-20261008/`.

### Contrat de mesure préenregistré

`compare` exige **max channel error ≤ 6** et **mean absolute channel error ≤ 0.15** (RGBA opaque, trois canaux RGB mesurés). La qualification observée dépasse ce gate : **0 écart** dans les deux fixtures, sans assouplissement post-test. L'oracle négatif injecte une vraie différence numérique de cinq niveaux et déclenche le comptage attendu.

Attention : le champ radial est une **approximation** signée autour des courbes organiques, pas un SDF à distance euclidienne exacte; la composition sort en RGB opaque sans profil PNG de couleur final. Aucun `TopologyEvent` merge/split, aucune hiérarchie d'identité ni test de continuité cross-host n'est implémenté en F1.

## Limitations et gates ouverts

1. **F1 est un contrat rendu hors écran, pas un moteur produit distribué.** Pas de packaging, de release, de SDK public ni de licence source blob.in résolue. Aucun code du snapshot GPL/AGPL n'a été copié.
2. Un trou et un contour organique fixes ne valident pas encore les événements topologiques E02 (merge/split, trous qui apparaissent, IDs stables à travers re-tessellation).
3. Le test E11 **perte GPU en cours d'animation** est **NOT_RUN**. La panne injectée est avant dispatch et le mode GPU indisponible est simulé via une configuration Vulkan invalide.
4. Parité GPU uniquement sur une RTX 3070, Vulkan et deux DPR. D'autres GPUs, backend software Vulkan, intégration GPUI, contraste, reduced-motion, DCI-P3/sRGB et p95 sont **NOT_RUN**.
5. Le CPU ne dépend pas du GPU à l'exécution mais le crate F1 contient `wgpu` pour l'adaptateur ; l'extraction du core en crate sans dépendance GPU est une suite proposée.
6. Le prochain gate causal prioritaire est **F2** : `TopologyEvent` merge/split/hole avec oracle de composants/holes, epochs et identité du contenu; ensuite **F3** matériaux et heightmaps complexes.
