## Implemented

Original, independent `experiments/blobin-next-01/F3/` Rust/WGSL code using qualified
F2 and F1 as path dependencies. No bytes were copied from the historic blob.in
GPL/AGPL-ambiguous snapshot. No F1/F2 changes and no changes to in.gnu6/Gnosix.

- Four concrete presets: **ceramic**, **gel**, **brushed metal**, **paper**. This is not
  a general material-node graph or production renderer.
- Shared scene topology, semantic IDs, epoch and digest are owned by F2.
  The F3 field is independently implemented in Rust/WGSL and checked against F2.
- Approximate signed contour, analytic heightfield, finite-difference normals,
  directional relief/rim lighting, grain and a deterministic two-source Gaussian
  heatfield controlled solely by `heat_strength`. No user telemetry.
- Foreground alpha is applied once in linear working RGB; composited over an
  opaque fixed background and encoded sRGB to 8-bit RGBA PNG. This does not
  qualify arbitrary transparency export, HDR or wide-gamut correctness.
- Separate GPU offscreen compute output stores RGBA and float analytics
  (`height`, `heat`, `mask`, `normal_z`) for independent numeric comparison.
- Image comparison is not the topology oracle: F2's binary field and flood-fill
  counts verify geometry, connected components and holes for all variants.

## Boundaries / next gate

The emitter projects a fixed two-lobe F2 scene. It does not yet have arbitrary
Boolean path geometry, self-intersections, third-party materials, multi-pass
shadows/blur/bloom, dirty rectangle scheduling, animated heat decay, dynamic
material graph, user-authorized host adapter, GPUI integration or production
licensing. CPU-compatible fallback is proven for GPU **unavailability**, not
physical device loss during an active GPU frame. F4 must qualify multi-pass
effect ordering, bounded failures and reduced-motion semantics; it is a
separate operator-prioritized gate.

No Git push, merge to main, public docs update or live runtime deploy authorized.
