## Implemented in the clean-room lab

- `Scene` owns two stable product-space IDs, logical viewport, phase, `Layout` and monotonic `epoch`.
- `Engine::transition(Action)` defines the **typed** legal transitions `Split → Merge → PunchHole → SealHole → Split`. Each accepted action emits a deterministic `TopologyEvent` containing before/after topology counts, epoch, stable IDs, semantic digests. Invalid transitions return an error without modifying state or event log; epoch increment is checked.
- One *canonical approximate signed field* describes two organic lobes with stable hit ownership; a punched-through hole cannot be hit. Renderers cannot mint scene identities.
- Independent 4-connected foreground/background flood-fill counts observed **connected components** and fully bounded **holes** from a canonical binary field, CPU-rendered RGBA and GPU-readback RGBA. Each source must agree; a mutated mask that connects the lobes must be rejected.
- Fully original GPU offscreen compute backend `wgpu 30.0.1` / Vulkan / WGSL with Naga syntax and semantic validation. CPU path requires no working GPU; fallback is explicit.
- Fixed reproducible sequence saved as five scene PNGs per backend per DPR, five difference PNGs per DPR, a semantic/topology ledger and an event ledger. All fixtures are synthetic.

## Proof boundaries

- All topology claims are **raster topology at these resolutions**, not continuous topology for arbitrary vectors. The source grammar is deliberately limited to two lobes and one round hole. Generic boolean geometry, nested holes, self-intersection, tangencies, movement, hierarchical reparenting, occlusion and multiple simultaneous topology transactions are **NOT PROVEN**.
- An event is an **engine-authorized semantic operation**, not an inference from GPU shading. The `TopologyEvent.before/after` expected counts are checked against independently measured raster masks in the tests and CLI.
- `F2_GPU` creates a Vulkan device per frame for this lab, **not** a shipping performance-oriented frame scheduler.
- CPU recovery for an unavailable GPU is verified; loss of an **active physical GPU device** and continuous animation handoff are **NOT RUN**. No host adapter or accessibility integration is claimed.
- Historical blob.in snapshot is **not** modified or licensed by this work. No source/publication decision, external push, merge, release or production integration.
- F3 materials/height/heat and F2 generalization are possible next gates but are not silently promoted to the in.gnu6 Main Quest.
