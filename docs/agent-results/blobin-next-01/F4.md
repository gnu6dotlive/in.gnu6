## Implemented evidence

The newly authored F4 Rust/WGSL laboratory at `experiments/blobin-next-01/F4/` adds an explicitly ordered, bounded graph of four postprocess passes above the qualified F3 material renderer:

1. **Shadow:** limited 2-pixel offset test against F2-owned geometry; bounded darken.
2. **Blur:** separable box-filter kernel, with radius at most 8 physical pixels; GPU computes an equivalent 2D bounded kernel per pixel.
3. **Bloom:** thresholded original source luminance, box-filter and bounded additive compositing.
4. **Echo:** one previous RGBA frame, `3:1` current-to-previous integer-weighted blend; reset on F2 semantic epoch change or reduced-motion, bounded to one frame.

Rust `Plan` validates the pass order, pixel budget of **1,048,576**, maximum radius and clipped conservative dirty halo `2+2r`. F2 remains the only owner of semantic identities, topology and hit tests; each projection carries exact F2 scene digest and topology. Actual F4 rendering is **full-frame**: the halo math is tested, but incremental GPU scissoring and dirty rectangle execution are not implemented.

The new Vulkan GPU backend reads an actual F3 GPU material frame, verifies the F3 material mask against F2's canonical geometry, then runs **four distinct `wgpu 30.0.1` compute dispatches** with explicit ping-pong buffers and a final RGBA readback. CPU is a separately authored reference with the same bounded effects. The new WGSL is parsed and validated by Naga.

## Non-qualification and open gates

**DO NOT treat this F4 lab as full production resilience qualification.** A true physical GPU loss during an active dispatch, reacquisition of a device, and mid-animation CPU continuity are **NOT_RUN**. The negative tests cover unavailable Vulkan and pre-dispatch injection only.

The blur is a **separable box filter, not a bilateral filter**. The bloom is a basic bounded threshold effect; not a final multiresolution HDR implementation. Full-frame GPU execution does not validate incremental dirty-scissor behavior. Cold-idle zero-submission proof, multi-GPU parity, GPU steady-state frame timings/p95, thermal/power budgets, presentation scheduling, 50 simultaneous organic shapes, host/GPUI integration, a11y and complete alpha/HDR color management remain **NOT_PROVEN**.

The F4 milestone's **working effect graph** is implemented and CPU/GPU-qualified; **F4 resilience closure is still pending**. This is not authority to merge, push, publish, release or change any F1–F3, Gnosix, in.gnu6 or the GPL/AGPL-ambiguous blob.in donor.
